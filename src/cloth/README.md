# cloth：モデルの服を布として動かす

Three.js のモデルのスカートやワンピースの裾を、布のシミュレーションで動かします。骨で動くモデル（VRM など）でも、骨のない部品に分かれただけのモデル（3D 生成のモデルなど）でも使えます。

- このフォルダだけで完結しています。依存は `three` だけで、engine のほかの部分も `@pixiv/three-vrm` も使いません。フォルダごと持ち出せます。
- モデルの骨や材質には触りません。布にするメッシュのジオメトリだけを差し替え、頂点を毎フレーム書き換えます。独自のシェーダーや輪郭線のパスがあっても、そのまま描けます。
- 計算は CPU（JavaScript）です。

## 使い方

### VRM の服（布にする服を指定する）

布にする服は、アバターごとに指定します。書いた服だけを布にし、ほかの服は骨と揺れもので動かします。名前から服の種類や生地を推すことはしません。

```ts
import { createVrmGarments } from './cloth';

// 読み込み直後（モーションを当てる前の姿勢）に作る。キーは材質名かメッシュ名
const cloths = createVrmGarments(vrm, {
  Skirt: { fabric: 'suiting' },                          // 腰から吊る服（骨の付き方で決まる）
  Knit: { fabric: 'jerseyOuter', over: ['Skirt'] },      // 肩に乗せる服。裾はスカートの外側に乗る
});

// 毎フレーム、姿勢が決まった後。配列の順に呼ぶ（吊る服 → 乗せる服）
for (const cloth of cloths) cloth.update(delta);
```

| 項目 | 意味 |
|---|---|
| `fabric` | 生地（下の「生地」）。名前か `{ bending, weight }` |
| `kind` | `hang`：腰から吊って垂れる（スカート・ワンピースの裾）。`rest`：肩と腕に乗せる（上着）。省くと、頂点の重みが腰・脚の骨（とそこから生えた揺れもの）に半分より多く付いていれば `hang`、ほかは `rest` |
| `over` | この服が外側に重なる服（ほかのキー。いくつでも）。いまは上着（`rest`）の裾が吊った服（`hang`）の外側に乗るときだけ効く。書かなければ当てない（シャツの裾をスカートの中に入れる着方もあるので決め打ちしない） |

キーの名前は、指定の側もモデルの側も末尾の「 (Instance)」を外して比べます。乗せる服が当たる体は、布にしない部品のうち、揺れもの（と、揺れものに運ばれる子の骨）への重みが 1 割未満のもの（体・顔・布にしない服。髪は外れる）です。

舞台（`StageManager`）では、`garments` にモデルの URL ごとの指定を返す関数を渡します。Studio はキャラ設定（`assets/studio/characters.json`）の `models[].cloth` を渡します。布は読み込み時に作るので、変えた指定は読み込み直したときから効きます。

### VRM のスカートだけ

```ts
import { createVrmSkirt } from './cloth';

// 読み込み直後（モーションを当てる前の姿勢）に作る。布にできるスカートがなければ null
const skirt = createVrmSkirt(vrm);

// 毎フレーム、姿勢が決まった後（モーション、vrm.update の後）
skirt?.update(delta);
```

布にするメッシュ・骨・当たる体は、VRM の決まりごとと形から選びます（下の「VRM で自動で選ぶもの」）。`skirt` でメッシュ名か材質名を指定もできます。

### VRM でない骨つきモデル（自分で指定する）

```ts
import { SkinnedCloth } from './cloth';

const cloth = SkinnedCloth.create({
  mesh: skirtMesh,                       // 布にする SkinnedMesh
  clothBones: [...skirtBones, ...legBones],   // この骨に付いた頂点が布になる
  reference: hipsBone,                   // 布全体が乗っている骨
  colliders: {                           // 布が当たる体（省くと当たり判定なし）
    meshes: [bodyMesh],
    bones: [hipsBone, spineBone, leftThigh, rightThigh, leftShin, rightShin],
    stopBones: [chestBone, leftShoulder, rightShoulder],
  },
});
cloth?.update(delta, { velocity: { x: 2, y: 0, z: 0 } });   // 風（m/s）は省略可
```

### 骨のないモデル（部品に分かれているだけのもの）

```ts
import { createMeshSkirt } from './cloth';

// 布にするメッシュ・当たる体・大きさの単位を、形から選ぶ
const skirt = createMeshSkirt(gltf.scene);

// 毎フレーム、モデルを動かした後（gltf.scene を動かす・回すと、布が遅れて付いてくる）
skirt?.update(delta);
```

自分で指定するときは `MeshCloth.create` を使います。

```ts
import { MeshCloth } from './cloth';

const cloth = MeshCloth.create({
  mesh: skirtMesh,              // 布にする Mesh
  colliders: [legsMesh],        // 当たる体。それぞれ固い物として、自分の動きに付いていく
  follow: modelRoot,            // 留めた点が乗る物体
  metresPerUnit: 0.37,          // モデルの 1 ユニットが何 m か
  held: (position) => position.y > 0.8,   // どこを留めるか（省くと上端）
});
```

| 項目 | 意味 |
|---|---|
| `mesh` | 布にするメッシュ |
| `colliders` | 布が当たる体のメッシュ。形は変わらないものとして、メッシュごとに自分の位置・向きに付いていく |
| `follow` | 留めた点が乗る物体（省くと `mesh` の親） |
| `held` | どこを留めるか。省くと上端（上の開いた縁と、その下 1.2cm）。頂点ごとの配列か、位置から決める関数でも渡せる |
| `metresPerUnit` | 1 ユニットが何 m か（既定 1）。`createMeshSkirt` の既定は、スカートの上端の輪の半径が 8.8cm になる値 |

`edge`・`restFit`・`solver` と、動かしている間の呼び出しは、骨つきの場合と同じです。

### 例

`examples/cloth`（`npm run example:cloth`、http://localhost:5193 ）が、3 通りの形で動く例です。

- 指定なし：VRM として読み、`createVrmSkirt` に任せる
- `?api=generic`：VRM の仕組みを使わず、骨の名前で直接指定する
- `?api=mesh&model=<URL>`：骨のないモデルを読み、`createMeshSkirt` に任せる

### 指定するもの

| 項目 | 意味 |
|---|---|
| `mesh` | 布にするメッシュ。ジオメトリを差し替える（`setEnabled(false)`・`dispose()` で元に戻る） |
| `clothBones` | 布にする骨。この骨の重みが `freeFrom` 以上の頂点が布になる。残りの頂点は、ほかの骨に付いたまま布の縁になる。揺れものの骨のほか、布の下で大きく動く骨（脚）も入れる |
| `clothWeights` | 頂点ごとに布の度合い（0〜1）を直接指定する（省略可。骨の重みで決めたくないとき） |
| `reference` | 基準の骨（人体なら腰）。布全体がこの骨に乗っているとみなす |
| `colliders.meshes` | 布が当たる体のメッシュ |
| `colliders.bones` | 体を切り分ける骨。体はこの骨ごとの固い部品になり、骨と一緒に動く |
| `colliders.stopBones` | この骨から先は当たり判定に入れない（布が届かない部位） |
| `freeFrom` | 布になるのに要る重みの割合（既定 0.05）。小さいほど布の範囲が広い |
| `edge` | 目の細かさ（既定 1.5cm）。布になる部分の辺がこのくらいになるまで三角形を分割する |
| `restFit` | 重力で垂れる分の補正の回数（既定 2、0 で補正なし） |
| `solver` | ソルバーの設定（`solver.ts` の `ClothOptions`。重力、布の張り、厚み、摩擦、空気抵抗など） |

### 動かしている間

| 呼び出し | 意味 |
|---|---|
| `update(delta, wind?)` | 1 フレーム進める。姿勢が決まった後に呼ぶ |
| `settle()` | 布を今の姿勢へ置き直す。基準の骨が 1 フレームに 40cm 以上動く・1 ラジアン以上回ると自動で呼ばれるので、ふつうは不要 |
| `setEnabled(false)` | 布を止めて、元の骨で動くメッシュに戻す |
| `raycast(ray)` → `startGrab(point)` / `moveGrab(point)` / `endGrab()` | マウスなどで布を摘む |
| `cloth.measure()` | 体への食い込み・布どうしの食い込み・計算時間などを返す（調整用） |
| `dispose()` | 元のジオメトリに戻して捨てる |
| `sleeping` | 布が止まって計算を休んでいるか（下の「止まった布を眠らせる」） |

### 生地（硬さと重さ）

布の曲げにくさと重さは、生地の実測値で決めます（`fabric.ts`）。Maya nCloth・Houdini Vellum・Marvelous Designer などと同じく、生地ごとに「曲げ剛性 B（N·m）」と「面積あたりの重さ（kg/m²）」を持ちます。単位のある値なので、メッシュの細かさやモデルによらず同じ硬さになります。

| 名前 | 生地 | 曲げ剛性 | 重さ | 曲げ長さ |
|---|---|---|---|---|
| `jersey` | 天竺ニット（肌着） | 0.0066 gf·cm²/cm | 126 g/m² | 0.81 cm |
| `jerseyOuter` | 天竺ニット（外衣） | 0.0162 | 159 | 1.01 |
| `shirting` | シャツ地（平織り） | 0.0270 | 125 | 1.29 |
| `suiting` | スーツ地（平織り） | 0.1249 | 246 | 1.72 |

値は Kawabata の測定器（KES-FB）で測った綿の生地のもの（Ramaiah ほか、fibre2fashion「Comparative Analysis of Low-Stress Mechanical Properties of Woven and Knitted Apparel Fabrics」表 3）。値を直接 `{ bending, weight }`（N·m、kg/m²）で渡すこともできます。

- **曲げ**：三角形の内側の辺ごとに、2 枚の面の角度を保ちます（Discrete Shells：Grinspun ほか 2003）。強さは k = 3B|e|²/(A1+A2) で、XPBD の柔らかさは 1/k。曲げは点ごとの本当の重さ（kg）で解きます。上着の布は標本点で計算するので、元のメッシュの面から標本点どうしの三角形を組み立てて同じ曲げを使います。
- **重さ**：点の重さ＝生地の重さ × 点の受け持つ面積。空気抵抗（布 1 枚あたり）も重さで割ります。
- **指定のしかた**：`createVrmGarments` の服ごとの `fabric`、`SkinnedCloth` / `MeshCloth` の `fabric`（省くとスーツ地）。
- **スカート**：置き換え前と見た目はほぼ同じで、計算は 1 人 1 フレーム 3.6ms から 5.1ms になりました（曲げを毎サブステップ解くため）。プリーツの折り目の固さ（`crease`）は、実測値が見つからないので今までの値のままです。

**分かっていること（上着）**：上着の布の動きは、曲げの強さではほとんど変わりません。ブレザーを歩かせたときのずれは、曲げを 0 にしても 35mm、スーツ地で 34mm、スーツ地の 1000 倍でも 29mm でした。ずれを決めているのはニット向けのほかの設定（辺を着せた形より 20% 長くしてゆるませる `ease`、どこまで離れてよいか `leash` など）です。ブレザーのような織物の上着には、伸びにくさ（Kawabata の引っ張り試験の値など）と芯地の硬さが要りますが、まだ入れていません。

### 座る・寝ると、広がった形を覚えさせる力を抜く

スカートは、モデルの広がった形を「長い距離」の拘束（5〜9cm 離れた点どうしをつなぐ力、solver の `shape`）で覚えています。立っているときはこれで裾の広がりが保たれますが、太ももを上げると、広がった形のまま押し上げられて、釣り鐘のように膨らみました。

`legs`（左右の [太もも, ひざ]）を渡すと、両方の太ももが真下から 45 度を超えて上がり始めたところで、この力を抜き始め、70 度で抜ききります。抜く・戻すは時定数 0.4 秒で少しずつ移ります（1 秒で 9 割、2 秒でほぼ全部）。布は体に沿って垂れ、形は体との当たりで決まります。片脚だけを上げたとき（蹴り上げ）は抜きません。`createVrmSkirt` は VRM の骨から `legs` を埋めます。

| モーション | 下がっている方の太ももの角度 | 抜いた度合い |
|---|---|---|
| 座る（pose_sit_seat・pose_stretch_legs） | 70 度 | 全部 |
| 机に頬杖で座る（desk_chin_rest） | 85 度 | 全部 |
| 立って寄りかかる（chin_rest） | 38 度 | なし |
| 歩く・走る・ダンス | 最大 18・20・34 度 | なし |

止めるときは `skirt.drapeWhenRaised = false` にします。今の度合いは `skirt.raised`（0〜1）で読めます。寝る姿勢も、太ももが水平になるので同じく抜けます（寝るモーションでは確かめていません）。

### 止まった布を眠らせる

外から布を動かすものがなくなると、布を落ち着かせてから止め、計算も休みます。既定で入っています。止まりきらずに細かく震え続ける（ガクブル）ことがなくなり、止まっている間の計算時間はほぼ 0 になります。

- **外から動かすもの**：腰の速さが変わる、腰が布を 0.3m/s より速く運んでいる（空気の抵抗が効く）、体の部品や留めた点が腰に対して動く、風、摘む操作。
- **眠るまで**：これらがない状態が 0.3 秒続くと減衰を強め始め、布の点が腰に対して十分遅くなったら眠ります。遅くならなくても、静かになってから 1.2 秒で必ず眠ります。
- **眠っている間**：布は腰に乗ったまま動きます。待機中のゆっくりした腰の揺れには付いていきます。
- **起きるとき**：腰の速さが変わる、体の部品や留めた点が眠ったときの位置から 4mm 動く、腰が 3 度傾く、風が吹く、摘む。眠ったときの位置と速さから計算を続けるので、眠るときも起きるときも布は跳ねません。
- **止めないとき**：`solver: { sleep: false }` で作るか、作った後に `cloth.cloth.o.sleep = false` にします。何も動かしていないのに揺れ続けてほしい布（スローモーションで小さな揺れを見せるなど）向けです。
- **調整**：`quietAccel`（m/s²）・`quietSpeed`（m/s）・`calmAfter`・`sleepAfter`（秒）・`sleepSpeed`（m/s）・`calmDamping`（1/s）・`wakeDist`（m）・`wakeAngle`（rad）。

上着（`createVrmGarments` の上着）も同じように眠ります。眠っている間は、骨が決める位置に付いていくので、呼吸や待機の揺れにも付いていきます。骨が決める位置からのずれは、眠っている間に少しずつ 0 に戻し（`restToFit`、既定 3/s。0 で戻さない）、止まった上着はモデルどおりの形になります。戻さないと、腕を下ろして立っているだけでもブレザーが平均 3cm ずれ、前が開いて襟の折り返しが浮いたまま止まっていました。骨が決める位置の速さが変わるか、体の部品が回って、その上の点が `wakeDist`（4mm）ずれるほどになると起きます（ずれの大きさは、回った角度とその部品の上の点のずれの長さから見積もります）。`over` で外側に重なるスカートを指定した上着は、スカートが起きている間は眠り始めませんが、眠った後にスカートが起きても、それだけでは起きません（眠っている間も、裾はスカートの外側に押し出します）。

`cloth.stats.watch`（上着は `knit.stats.watch`）に、そのフレームの判定に使った値（腰の加速度、体の部品の動き、ずれの見積もりなど）が入ります。起きすぎる・眠りすぎるときの調整に使えます。

## 骨のないモデルで自動で選ぶもの

- **布にするメッシュ**：下 1/3 に開いた裾があり、裾がいちばん広い部品。`skirt` で指定もできる。
- **当たる体**：スカートの裾より下まで伸び、スカートの高さと重なる部品（脚と腰。靴は下すぎ、ベルトは上すぎで外れる）。`colliders` で指定もできる。なければ当たり判定なしで動く。
- **大きさの単位**：スカートの上端の輪の半径が 8.8cm になる倍率。`metresPerUnit` で指定もできる。

布にできなかったときは `null` が返り、理由が `MeshCloth.skipped` に入ります。

## VRM で自動で選ぶもの

- **布にするメッシュ**：揺れもの（スプリングボーン）に付いた頂点を持つ部品のうち、形で選ぶ（下 1/3 に開いた裾があり、裾がいちばん広い部品）。材質名では選ばない。`skirt` で名前を指定もできる（`createVrmGarments` は指定した服を渡す）。
- **布にする骨**：腰か脚から生えている揺れものの骨と、脚の骨。袖・胸・髪の揺れものは入らない。
- **当たる体**：スカートの下まで伸びている部品（肌）を、腰・背骨・太もも・すねの骨ごとに切る。
- **基準の骨**：腰。

布にできなかったときは `null` が返り、理由が `SkinnedCloth.skipped` に入ります。

## 仕組み

- **ソルバー**（`solver.ts`）：XPBD。辺の長さ、曲げ、折り目の角度、布どうしの衝突、体との衝突と摩擦、空気抵抗と風を、1 フレーム 16 サブステップで解く。three.js にも依存しない。
- **体の当たり判定**（`sdf.ts`）：体の部品ごとに、骨の座標で符号付き距離の格子を作る。
- **骨つきメッシュへのつなぎ込み**（`SkinnedCloth.ts`）：分割した新しいジオメトリの全頂点を基準の骨に付け、布のワールド座標を「その骨のスキニング行列の逆」に通して書き戻す。描画側のふつうのスキニングで、布の位置にちょうど出る。
- **重力の補正**：モデルの形は、重力で垂れた後の形として扱う。作成時に基準の姿勢で布を落ち着かせ、垂れた分だけ、覚える形を逆へずらす。

## 確かめたこと

VRoid 製の VRM 2 体（スカート、ワンピース）で、歩く・走る・ダンス・座るを動かしました。骨のないモデルは、Tripo で作った 2 つ（下半身つきのスカート、スカートだけ）で、揺らす・回す・跳ねさせるを動かしました。

| | 値 |
|---|---|
| 布の点数 | 約 800〜1300 点（スカートだけのモデルは 2900 点） |
| 体への食い込み | 1mm 前後まで |
| 布どうしの食い込み（点の組） | 0〜5 組 |
| 計算時間 | 1 人あたり 1 フレーム 4〜5ms（3 人で 14ms、60fps を割った）。眠っている間は 0.1ms 以下 |
| 眠る割合 | 待機モーション（Standing Idle・Idle）20 秒で、スカートは時間の 82〜84%、上着は 62〜84%。起きるのは主に、重心の移動で脚が腰に対して 4mm 動いたときと、腕・肩が回ったとき |

## できないこと・注意

- 布は、上から吊られて垂れる服を想定しています（スカート、ワンピースの裾）。布の下の体は、布の高さの範囲だけを当たり判定にします。
- 布にするメッシュは、内側と外側のある閉じた袋ではなく、1 枚の面であること。uv が要ります。
- 椅子・床・手は当たり判定にありません。座ると、後ろの裾は座面を通り抜けて垂れます（座った姿勢では形を覚えさせる力を抜くので、垂れる量は前より大きくなります）。
- 布どうし・体との衝突は点だけで判定します。点の間隔より細かいすり抜けは防げません。
- 布にしたメッシュのモーフ（シェイプキー）は効かなくなります。
- 骨つきのモデル（`SkinnedCloth`）は 1 ユニット＝1m の前提です（厚みや目の細かさをメートルで決めているため）。骨のないモデル（`MeshCloth`）は `metresPerUnit` で渡せます。
- 骨のないモデルの当たる体は、形が変わらないものとして扱います（脚を曲げるなどはできません）。
- 作成時に、重力の補正のぶん 0.3〜0.5 秒かかります。
